Branch 05 · Fatigue-Collate

Projection & Collation brings every input together at each fatigue point.

The workbook defines the case, line/region, component, S-N, local response and exposure inputs. Fatigue-Collate then loops through load cases, components, arc length and trial clock angle before projecting the global curvature histories to each circumferential fatigue position.

What this branch must deliver

  • All input tables resolved into one fatigue calculation context.
  • T(t), Cx(t), Cy(t) read at the current arc-length location.
  • Projected curvature Cθ(t) for every trial component clock position.
Critical distinction from the source map: θ is the trial component clock position around the umbilical cross-section. It is not the environmental wave direction.
