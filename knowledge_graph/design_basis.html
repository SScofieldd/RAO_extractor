Branch 01 · upstream definition

Design Basis sets the rules before any fatigue calculation starts.

This branch converts project intent into a fatigue-ready basis: life, DFF, operating conditions, metocean representation, regular vs irregular method, directional treatment, binning and final load-case IDs.

What this branch must deliver

  • A traceable fatigue assessment basis.
  • A long-term environmental representation suitable for the selected fatigue method.
  • Representative load cases and exposure values ready for global analysis and collate workflows.
Key principle: if the basis is weak, every downstream fatigue result is weak. This page therefore focuses on decisions and setup quality, not only calculations.
