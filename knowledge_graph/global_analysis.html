Branch 03 · global response & extraction

Global Analysis creates the synchronized response histories used by the downstream fatigue chain.

This branch follows the master map exactly from the OrcaFlex global umbilical model, through static and dynamic analysis, into fatiguepp.py extraction, arc-length sampling, unit conversion and HDF5 storage.

What this branch delivers

  • Global response along arc length s.
  • Effective tension and x/y curvature histories.
  • Selected region / arc-length samples mapped to OrcaFlex nodes.
  • Standardized HDF5 datasets for downstream processing.
Key source principle: this stage produces global line response. It does not yet produce final component fatigue stress.
