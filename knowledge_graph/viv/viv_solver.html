The solver first decides which modes matter, then iterates hydrodynamic energy input and damping until each retained resonant case reaches steady power balance.

Follow Stage II from shedding match to mode ranking, then Stage III from hydrodynamic forces through iterative modal power balance to mode-superposed response.

Memory: Shed → Match → Map → Rank, then Mass → Lift → Loss → Loop → Modes.

Two memory chains

  • Stage III: Mass → Lift → Loss → Loop → Modes
  • Power-in/out maps are mode specific
  • Each surviving resonant mode is solved as a separate response case
