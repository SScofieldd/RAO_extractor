VIV Branch 02 · current → wake → excitation field

Turn the ocean current into the local fluid-excitation field that SHEAR7 will later match to structural modes.

This branch follows the theory chain in your VIV fundamentals and SHEAR7 notes: current flows around the cylinder, viscosity creates a boundary layer, separation forms an unsteady wake, alternating vortex shedding generates fluctuating lift, and the local shedding-frequency scale is estimated using the Strouhal relation.

Key equations from your study modules

Strouhal definition
St = fsD / V
Nominal local shedding frequency
fvortex(x) = St(x)V(x) / Dhydro(x)
Reynolds number
Re = V D / ν
Reduced velocity for Mode n
VR,n(x) = V(x) / [fnDhydro(x)]
Nominal lock-in centre
fvortex ≈ fn ⇒ VR ≈ 1/St; for St ≈ 0.2, VR ≈ 5

The notes explicitly warn that VR ≈ 5 is a nominal compatibility condition, not an automatic guarantee of positive power input. Actual excitation uses a finite lock-in band and favorable force–velocity phase.

Engineering QA before handing current data to SHEAR7

  • Current profile maps to the same riser positions as the modal coordinates.
  • Current is resolved normal to the local riser axis.
  • Hydrodynamic diameter includes the intended coating, marine growth or suppression-device basis.
  • Water-property units and coordinate conventions are consistent.
  • The current range is compatible with the modal frequency range you intend to export.
  • For a long-term study, keep any case weighting traceable to the project environmental basis.
Important separation of responsibilities: this branch tells us what wake-frequency field the current can create. The Structural / Modal branch tells us what the structure can naturally do. Stage II then performs the match.
