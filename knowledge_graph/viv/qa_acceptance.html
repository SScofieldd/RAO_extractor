QA / review checklist

  • OrcaFlex mode set covers possible shedding range.
  • Current is normal-resolved and mapped correctly.
  • D_hydro and added-mass assumptions are compatible.
  • Power-in/out maps are reviewed per mode.
  • Power cutoff sensitivity is checked.
  • Lift/damping sets match Re and suppression configuration.
  • A/D converges for each resonant case.
  • Enough nonresonant modes are retained.
  • Project acceptance criteria are explicitly documented.
