Study-grounded VIV / SHEAR7 branch

Modal analysis defines the vibration patterns available to VIV before the current is allowed to “choose” which modes can be excited.

This page focuses on the structural modal information that SHEAR7 receives from OrcaFlex and the QA required before Stage II matching.

Memory: Modes first. The current does not create a mode shape; it can only energize structural patterns that already exist.

Stage I must deliver

  • Natural frequencies f_n
  • Mode shapes Y_n(x)
  • Curvature-compatible modal data Y_n″(x)
  • Aligned structural coordinates
  • Sufficient frequency and spatial resolution

QA / review checklist

  • Mode set extends beyond maximum possible shedding frequency.
  • Frequency units are consistent.
  • Current profile and modal coordinates align.
  • High-mode shapes have sufficient spatial resolution.
  • Mode orientation / normalization are consistent.
  • Added-mass assumptions remain compatible.
