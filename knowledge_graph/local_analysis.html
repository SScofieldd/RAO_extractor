Branch 04 · UFlex local mechanics

Local Analysis reduces detailed cross-section behavior into parameters used by the component stress solvers.

This page follows the Stage 1B map: detailed UFlex cross-section model → axial tension and curvature/bending analyses → critical local node selection → TSLF, CSLF, friction range F and slip curvature Cs → single-T parameters → variable-T fits.

What this branch delivers

  • Reduced local response parameters at a validated critical node / clock position.
  • Single-T local parameters: TSLF, CSLF, F and Cs, plus slip stress and representative tension.
  • Variable-T relationships for Cs(T), F(T), and optional baseline / pressure stress.
Source-map role: this branch supplies local parameters. The global branch supplies time histories. They meet later in the component stress reconstruction workflow.
